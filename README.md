# WHATSAPP FREE MIC 🎤 — V9

- Extension version: 9.0.0 (Manifest V3)
- Popup redesigned with a black/red sound-mixer layout inspired by the supplied reference.
- Password gate: `FBX MUNNA`; a successful unlock is saved locally for this browser profile.
- Works with WhatsApp Web only, using the original project's content scripts and audio injector.

## Important
The password gate is a casual local lock, not strong security: the password is stored in the extension's client-side code and can be discovered by someone who can inspect the extension files. It does not protect WhatsApp accounts or chats.

The extension cannot suppress browser/extension warnings generated by the browser or its installation policy. This package uses Manifest V3 and only declares the storage permission and WhatsApp Web host access; any warning shown by a browser may depend on that browser/version or installation method.

Audio processing is subject to browser and device limitations. Excessive gain can distort audio. Use the extension only with the microphone and calls you are authorized to use.
